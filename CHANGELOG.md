# Changelog

All notable changes to AmazeLPD are documented here.

## [1.0.0] — 2026

### Initial Release

- RFC 1179 compliant LPD/LPR listener on port 515
- Windows service with automatic startup
- Per-queue configuration (server, branch, Param1, Param2)
- Concurrent queue processing — one worker thread per active queue
- Job history with full audit log
- Queue pause and resume
- CSV bulk import for queue configuration
- 7-day trial licence
- Single server perpetual licence
- 5-server pack perpetual licence with 2 years of updates
- Annual subscription licence
- WPF management UI (AmazeLPD Manager)
- System tray integration
- SQLite embedded database — no SQL Server required
- Supports AS400, Linux, Unix, SAP, mainframe, and any LPR-capable client
- XML and legacy envelope formats
- Automatic job retry on service restart
- Configurable job timeout and history retention
- iSeries formatting removal option
- CRLF conversion options for legacy text streams
